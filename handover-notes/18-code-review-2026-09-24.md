재검사 때 아래를 기준으로 항목을 다시 판정할 것. 본문 표는 원본 그대로 두었다.

### A. 기획 확정 사항

1. **방문 인증 = GPS만.** 사진·영수증 업로드 없음, 관리자 심사 화면 없음.
   - 대상: 추천받은 가게 전부가 아니라 결과 화면에서 **'예약하러 가기'를 누른 가게만**. 그래서 예약 클릭 기록을 서버에 남긴다(명세 [3-1 BE]).
   - 절차: 인증 버튼 → 폰 위치가 가게 300m 안이면 통과 → +500P.
   - 같은 가게 **중복 인증만 막으면** 된다.
   - 명세 기준 행: [3-1 BE]·[3-4 BE]·[3 FE]. [3-2 BE] 영수증 업로드·[3-6 FE+BE] 관리자 심사는 보류.
2. **포인트 적립 사유는 두 종류뿐**: 방문인증(+500) / 폰에서 옮김(로컬 포인트 이관). 쿠폰 사용(차감)이 생기면 종류를 추가. 규칙 원문은 정책정의서 3장.
3. **지난 추천 결과**: 계정당 최근 50건, 넘으면 오래된 것부터 삭제. 90일 지난 것도 삭제. 두 숫자는 설정값으로.
4. **비회원 데이터는 서버에 저장하지 않는다**(카카오 로그인 유도). 단 홈 3단계 입력 조건은 지금처럼 폰에 저장해 앱이 튕겨도 다시 입력하지 않게 유지.
