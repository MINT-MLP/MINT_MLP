## B. 종류·메뉴 칩 (PC 줄바꿈)

1. [PC] 1단계 1차 목적 "밥" → 종류 칩이 여러 줄로 전부 보이고 오른쪽이 잘리지 않는다.
2. [PC] "술", "카페"도 같은지 본다. 칩이 많으면 3줄 이상도 정상.
3. [PC] 1차 "메뉴 콕" → 추천 메뉴 칩(국밥·냉면…)이 여러 줄로 전부 보인다. 2차 메뉴 콕도 같은지.
4. [폰] 같은 화면에서 칩이 한 줄이고 옆으로 밀린다(예전과 같음).
5. [둘] 칩을 눌러 선택·해제가 되고, 밥에서 대분류를 고르면 아래 "세부 종류" 줄이 나온다.

## C. 로그인 (익명 로그인 제거)

1. [둘] 프로필 탭 → 카카오 로그인 → 돌아오면 프로필에 닉네임·사진이 보인다.
2. [둘] 로그인 상태에서 새로고침 → 로그인이 유지되고, 잠깐이라도 "로그인" 안내 카드가 보이지 않는다.
3. [둘] 로그아웃 → 로그인 안내 카드가 다시 보인다. 오류 없이 홈·추천이 된다.
4. [둘] 로그아웃 상태에서 새로고침 → 로그인 안내 카드가 깜빡임 없이 보인다.
5. [둘] 로그인한 채 추천을 받는다 → 프로필의 "계정 기록"에 방금 기록이 보인다(아직 옛 기록 방식. 3번 작업에서 바뀜).
6. [PC] 개발자 도구 → Application → Local Storage에서 `sb-`로 시작하는 키 안의 user에 `"is_anonymous":true`가 없다(로그아웃 상태면 키 자체가 없음).
7. 확인만: Supabase dev → Authentication → Users에 새 익명 사용자가 생기지 않는다(앱을 몇 번 열어본 뒤).

## D. 비회원 흐름 (영향 없어야 함)

1. [둘] 로그아웃 상태로 혼자 정하기 → 추천까지 끝난다.
2. [둘] 결과에서 "다시 추천받기" 사유 3개 각각 → 새 결과가 나온다.
3. [둘] 공유하기 → 링크를 다른 브라우저(시크릿 창)로 열면 결과가 보인다. 투표가 된다.
4. [둘] 다같이 정하기 → 링크 생성 → 다른 브라우저에서 참여·제출 → 호스트 화면에 인원이 올라가고 결과가 나온다.
5. [둘] 피드백 남기기 → 전송 완료.
6. [PC] 개발자 도구 Console에 빨간 오류가 없다. Network에서 Supabase `events` 요청이 201(또는 204)이다.

## E. 3단계 지역·출발지 (main hotfix 반영분)

1. [PC] 직접 입력 → 검색 → 드롭다운에서 선택 → 칩으로 바뀐다 → X로 지우면 빈 입력창.
2. [폰] 직접 입력 칸을 누르면 전체 화면 검색 시트 → 고르면 닫히며 칩이 채워진다. 뒤로가기로 닫힌다.
3. [PC] 자동 중간지점 → 출발지 2칸에 검색 → 선택 → 칩. 칸 추가(최대 6)·삭제가 된다.
4. [폰] 출발지 칸을 누르면 "출발지 검색" 시트 → 고르면 해당 칸이 칩으로.
5. [PC] 출발지에 글자를 치다가 다른 곳을 클릭하면 검색어가 지워진다(의도된 동작).
6. [둘] 출발지 2곳을 골라 추천까지 → 중간지점 결과가 나온다.
