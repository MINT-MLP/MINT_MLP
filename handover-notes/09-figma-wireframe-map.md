## 이 문서의 용도

**MCP 호출 예산 절약용입니다.** 아래 node ID를 알고 있으면 `get_metadata`로 구조를 다시 조회할 필요 없이 바로 `get_design_context`나 `get_variable_defs`를 부를 수 있습니다. 구조 조회 한 번이 결과 22만 자짜리라 한 번 한 걸 재활용하는 게 맞습니다.

단, 디자이너가 프레임을 새로 만들거나 지우면 ID가 바뀝니다. 호출이 "node not found"로 실패하면 이 표가 낡은 것입니다.

## MCP 접근 조건 실측 결과

| 조건 | 결과 |
|---|---|
| 파일 뷰어 권한 | **실패.** "you don't have edit access" |
| 파일 편집 권한 + View 시트 | **성공** |
| Dev Mode 활성화 | 불필요 |
| Dev 또는 Full 시트 | 불필요 |
| Starter 플랜 파일 | 미확인. 문서상 월 20회 가능 |

주의:
- 파일에 뜨는 Dev Mode **Request access** 버튼은 누르지 말 것. 유료 시트 요청이고 원격 MCP와 무관
- `get_variable_defs`는 페이지 루트 `0:1`을 거부함. 실제 프레임 node ID가 필요
- `get_metadata`는 `0:1` 허용
- 한국어 블로그의 "Dev/Full 시트 필수"는 **데스크톱 서버** 기준. `127.0.0.1:3845`가 나오면 그쪽
